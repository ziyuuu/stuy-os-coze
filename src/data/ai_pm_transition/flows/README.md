# 流程文件

本目录保存 `ai_pm_transition/` 的正式流程文件。

## 文件

- `month_plan_generation_flow.md`：月计划半自动生成流程。
- `monthly_lesson_prep_flow.md`：月备课派生流程。
- `monthly_review_flow.md`：固定月复盘流程。
- `week_plan_generation_flow.md`：固定周计划生成流程。
- `weekly_lesson_prep_flow.md`：周备课派生流程。
- `weekly_review_flow.md`：固定周复盘流程。
- `daily_plan_generation_flow.md`：固定日计划生成流程。
- `daily_lesson_prep_flow.md`：日备课派生流程。
- `daily_review_flow.md`：固定日复盘流程。

## 边界

- 流程文件定义任务如何运行。
- 模板文件仍保存在 `../templates/`。
- 开发草案和试运行设计记录保存在 `../dev/`，不作为正式运行入口。
