# 周备课流程

## 流程说明
根据本周计划进行系统备课。

## 前置条件
1. current_status.md 中的当前阶段已定义
2. current_month_plan.md 已按正式月计划模板生成

## 必须读取的文件（按顺序）
1. current_status.md - 当前状态
2. current_month_plan.md - 月计划
3. current_week_plan.md - 周计划
4. templates/week_prep_template.md - 周备课模板

## 流程步骤
1. 回顾本周学习主题
2. 准备本周核心资源
3. 设计周练习计划
4. 准备周复习材料

## 验证清单
- [ ] 学习主题明确
- [ ] 周资源已准备
- [ ] 周练习计划已设计
- [ ] 周复习材料已整理

## 禁止规则
- 不跳过后置条件检查
- 不跳过文件读取
