# 月备课流程

## 流程说明
根据本月计划进行系统备课。

## 前置条件
1. current_status.md 中明确允许进入月计划

## 必须读取的文件（按顺序）
1. current_status.md - 当前状态
2. master_plan.md - Master Plan
3. current_month_plan.md - 月计划
4. templates/month_prep_template.md - 月备课模板

## 流程步骤
1. 回顾本月学习主题
2. 准备本月核心资源
3. 设计月度练习计划
4. 准备月度复习计划

## 验证清单
- [ ] 学习主题明确
- [ ] 月度资源已准备
- [ ] 月度练习计划已设计
- [ ] 月度复习计划已制定

## 禁止规则
- 不跳过后置条件检查
- 不跳过文件读取
