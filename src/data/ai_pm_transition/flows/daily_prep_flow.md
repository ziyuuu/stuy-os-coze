# 日备课流程

## 流程说明
根据当日计划进行备课准备。

## 前置条件
1. current_month_plan.md 已按正式月计划模板生成
2. current_week_plan.md 已按周计划模板生成
3. current_daily_plan.md 已按日计划模板生成

## 必须读取的文件（按顺序）
1. current_month_plan.md - 月计划
2. current_week_plan.md - 周计划
3. current_daily_plan.md - 日计划
4. templates/daily_prep_template.md - 日备课模板

## 流程步骤
1. 回顾当日学习目标
2. 准备学习资源
3. 设计练习题
4. 准备复习材料

## 验证清单
- [ ] 学习目标明确
- [ ] 资源已准备
- [ ] 练习题已设计
- [ ] 复习材料已整理

## 禁止规则
- 不跳过后置条件检查
- 不跳过文件读取
