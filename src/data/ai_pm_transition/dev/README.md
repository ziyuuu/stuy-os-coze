# Dev 草案目录

本目录保存 `ai_pm_transition/` 月计划机制的临时草案。

当前文件只用于保留讨论、审校和试运行设计记录，不作为正式运行入口。

正式版本：

- 月计划模板：`../templates/month_plan_template.md`
- 月计划生成流程：`../flows/month_plan_generation_flow.md`
- 月备课派生流程：`../flows/monthly_lesson_prep_flow.md`

## 文件

- `month_plan_template_v1.md`：临时月计划模板草案。
- `month_plan_generation_flow_v1.md`：半自动月计划生成流程草案。
- `monthly_lesson_prep_flow_v1.md`：月备课派生流程与边界草案。

## 边界

- 不生成具体月份计划。
- 不修改 `master_plan.md`。
- 不把计划写成完成事实。
- 不替代 `templates/month_plan_template.md`。
- 不替代 `operating_rules.md`。
- 正式运行时应使用 `../templates/month_plan_template.md`、`../flows/month_plan_generation_flow.md` 和 `../flows/monthly_lesson_prep_flow.md`。
