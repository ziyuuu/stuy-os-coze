# 月计划模板 v1 草案

本模板用于 `ai_pm_transition/` 的月计划实例。

`current_month_plan.md` 是当前月计划窗口，不是模板，也不是历史母本。月计划必须从当前可用于月计划生成的 `current_stage.md` 派生，并结合 `annual_plan.md`、`master_plan.md` 和 `current_status.md` 校验边界。允许生成月计划不等于阶段已经进入实际学习执行。
