# Module 02 月备课：旧资产与能力缺口盘点

- 关联月计划：`mvp_memory/ai_pm_transition/current_month_plan.md`

- 对应模块：模块 2：旧资产与能力缺口盘点

## 2. 备课定位

- 本次备课服务的计划目标：
  - 盘点旧成果、旧资产和能力缺口。
  - 判断哪些材料可作为 Phase 1 输入，哪些只能作为历史材料。
- 本次备课的教学重心：
  - 把旧资产从“材料列表”变成“可继承性判断”。
  - 强制区分历史存在、当前能力、可复用输入和需重练缺口。
- 本次备课不承担的内容：
  - 不评价旧产出的优劣。
  - 不把旧资产直接转成作品集证据。
  - 不修改旧产出正文。

## 3. 知识地图

- 涉及知识域：
  - 资产审计。
  - 能力证据和历史材料边界。
  - 产品文档链路：问题简报、精益画布、PRD、Backlog、用户故事 / AC、指标。
  - 资源选择与能力缺口对齐。
- 核心概念：
  - 旧资产：用户过去写过、导出过或沉淀过的材料。
  - 当前能力证据：能在当前任务中被重新调用并产出可检查结果的能力表现。
  - 可继承材料：经过审计后可作为 Phase 1 输入或脚手架的材料。
  - 需重练缺口：旧材料暴露但当前无法稳定调用的能力。
  - 仅归档：保留历史价值，但不进入本月训练或 Phase 1 输入。
- 概念关系：
  - 旧资产不是能力证据。
  - 旧资产经过审计后，才能被归为可继承、需重练、仅归档或暂不使用。
  - 能力缺口决定后续资源和练习，而不是资源清单决定学习任务。
- 先后依赖：
  - 先确认旧资产入口。
  - 再用产品流程维度分类。
  - 再判断可继承性和缺口。
  - 最后形成旧资产与能力缺口清单。
- 常见混淆：
  - 把“Notion 有页面”当成“可用证据”。
  - 把“旧 PRD 存在”当成“当前 PRD 能力稳定”。
  - 把长期学习系统项目当成主作品集启动。
  - 把旧资产审计做成资料搬运。

## 5. 教学顺序

- 步骤 1：建立旧资产地图，按来源分为 Playbook、Gemini 输出、长期学习系统、学习图书馆、旧练习。
- 步骤 2：用产品流程维度分类资产：
  - 问题定义。
  - 用户和场景。
  - 价值主张。
  - 需求 / PRD。
  - Backlog / 用户故事 / AC。
  - 指标。
  - 资源和学习系统。
- 步骤 3：为每个资产打处理结论：
  - 可继承。
  - 需重练。
  - 仅归档。
  - 暂不使用。
  - 待补正文。
- 步骤 4：把“需重练”和“待补正文”转为能力缺口，而不是直接转为新学习任务。
- 步骤 5：形成旧资产与能力缺口清单。

## 6. 练习与脚手架

- 练习入口：
  - 旧资产审计练习。
  - 能力缺口归类练习。
  - 可继承 / 不可继承判断练习。
- 脚手架：
  - 旧资产审计表：
    - 资产名称。
    - 来源路径。
    - 对应产品流程环节。
    - 当前可用信息。
    - 证据类型。
    - 处理结论。
    - 缺口。
    - 后续动作。
  - 能力缺口表：
    - 缺口名称。
    - 暴露来源。
    - 影响的本月产出。
    - 需要的资源或练习。
    - 是否进入本月。
- 示例 / 反例：
  - 示例：长期学习系统 PRD 可作为“旧 PRD 表达样本”，但需重新检查用户问题、指标和验证路径是否可迁移。
  - 反例：因为旧 PRD 存在，所以直接把 PRD 能力写成已恢复。
- 质量标准：
  - 每类旧资产都有处理结论。
  - 处理结论必须能解释原因。
  - 缺口必须连接到本月目标或 Phase 1 输入。
  - 不把旧产出存在本身写成能力。

## 7. 检查问题

- 理解检查：
  - 旧资产和当前能力证据有什么区别？
  - 哪些旧资产可以作为 Phase 1 输入，哪些只能归档？
  - 能力缺口如何反向决定资源调用？
- 产出检查：
  - 旧资产清单是否覆盖 Playbook、Gemini 输出、长期学习系统和学习图书馆？
  - 每条资产是否有处理结论？
  - 能力缺口是否具体到可练习的产品能力？
  - 是否标出待补正文或待复核材料？
- 边界检查：
  - 是否把长期学习系统写成主作品集？
  - 是否把旧产出写成当前完成事实？
  - 是否新增了月计划没有批准的作品集任务？

## 8. 周 / 日备课入口

- 需要周备课展开的内容：
  - 阶段 1 的资产入口梳理。
  - 阶段 3 的审计集中处理。
  - 阶段 5 的可延续输入整理。
- 需要日备课展开的内容：

  - 当天至少给几条资产写处理结论。
  - 当天要补哪些旧入口。
- 暂不展开的内容：
  - 旧资产重写。
  - 作品集包装。
  - 对旧产出的正式评价。
