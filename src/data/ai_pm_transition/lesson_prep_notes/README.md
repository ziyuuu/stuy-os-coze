# Lesson Prep Notes

本目录是 `ai_pm_transition` 的备课材料专用目录。

## 用途

- 保存月备课、周备课和日备课材料。
- 承接已确认的计划文件，说明 Codex 后续如何引导学习、如何设计练习、如何检查产出。
- 为后续 Codex 线程提供知识地图、资源导航、资料理解记录、脚手架和检查入口。
- 记录 AI 自我备课理解，不代表用户已经学习、完成或产出。

## 边界

- 不保存月计划、周计划或日计划正文。
- 不保存月回顾、周回顾或日回顾。
- 不记录完成事实。
- 不评价用户产出。
- 不把 Codex 自己的资料阅读或理解写成用户学习事实。
- 不更新 `current_status.md` 或 `current_stage.md`。

## 推荐结构

```text
lesson_prep_notes/
├── YYYY/
│   ├── month_lesson_prep_YYYY_MM/
│   ├── week_lesson_prep_YYYY_WW/
│   └── daily_lesson_prep_YYYY_MM_DD.md
```

具体结构以正式流程文件为准：

- `../flows/monthly_lesson_prep_flow.md`
- `../flows/weekly_lesson_prep_flow.md`
