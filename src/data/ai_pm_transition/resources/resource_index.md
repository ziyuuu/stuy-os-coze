# 资源索引

本文件是 `ai_pm_transition/` 的资源入口索引，用于说明资源候选池、复核机制和使用边界分别在哪里维护。

本文件不是学习路径，不推荐具体资源，不声明任何资源已批准、当前、权威或高质量。

## 资源文件

| 文件 | 用途 |
| --- | --- |
| `resource_catalog.md` | 资源候选池、资源类目、阶段建议、能力到资源映射、学习方法论购买 / 观看建议、谨慎 / 排除资源、版权和数据边界摘要 |
| `resource_review.md` | 资源复核机制、复核节奏、检查项、复核输出和排除规则 |
| `resource_watch.md` | 后续可用于观察待补充或待跟踪资源 |
| `source_materials/` | 原始输入材料和来源资料归档 |

## 资源分类

资源候选池按以下类目维护在 `resource_catalog.md`：

- 已学 / 需复习资源。
- 产品基础稳定资源。
- C 端产品补强资源。
- Human-AI Interaction 与 Conversation UX 资源。
- AI PM / LLM / RAG / Agent / eval 高时效资源。
- AI 产品分析、观测与运营资源。
- AI 产品商业化、定价与增长资源。
- 学习方法论与自我调节资源。
- 作品集实践资源。
- 岗位、JD、面试与职业市场资源。
- 不推荐 / 谨慎资源。

## 已批准资源

- 当前无资源被本索引声明为已批准学习任务。
- 资源进入年度、阶段、月、周或日计划前，必须结合当时目标、阶段、时间投入、版本状态和版权边界进行二次复核。

## 待复核资源

- 待复核资源以 `resource_catalog.md` 中的状态字段为准。
- 复核规则以 `resource_review.md` 为准。

## 使用边界

- 当前不推荐具体课程、博客、书籍、工具或资料。
- 当前不声明任何资源当前、权威或高质量。
- 当前不将资源写成学习路径。
- 当前不绑定具体 Resource ID 到下级计划。
