# 术语表

本文件用于固定本工作区的常用中文术语，避免同一概念在不同文件中反复变体。

| 英文术语 | 稳定中文术语 | 说明 |
| --- | --- | --- |
| plan | 计划 | 用于总计划、年度计划、阶段计划、月计划、周计划、日计划。 |
| review | 复盘 | 用户完成工作后的事实整理和反思记录。 |
| evaluation | 评价 | 对产出或系统运行结果进行结构化判断。 |
| user output | 用户产出 | 用户原始提交、练习结果、作品或工作记录。 |
| artifact | 产物 / 留痕 | 可被保存、审查和引用的文件或记录。 |
| closed loop | 受控闭环 | 基于评价证据提出、批准并应用调整的过程。 |
| current status | 当前状态 | 工作区当前事实状态，不追加流水账。 |
| master plan | 总计划 | 12 个月学习方向和稳定边界的最高层计划。 |
| rubric | 评价标准 | 用于评价产出或过程质量的规则。 |
| capability | 能力项 | 学习和训练所面向的能力单元。 |

## 使用规则

- 用户可读文件优先使用中文术语。
- 文件名和目录名保持英文 snake_case。
- 必要技术词可以保留英文，例如 `Codex`、`AI PM`、`TBD`。
- 不为同一内容创建完整中英双语重复版本。
